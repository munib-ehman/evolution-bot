# Evolution v1.1 — Approved Shopify Operator

Evolution v1.1 turns the existing read-only copilot into an operator that can prepare real Shopify changes and apply them only after the merchant reviews and approves a before/after proposal.

## Release capabilities

- Apply reviewed product title, description, SEO, tag, and image alt-text fixes.
- Prepare and create unpublished product drafts from winning-product research.
- Create or update collections and their product membership.
- Create reviewed code and automatic discounts.
- Show every proposed, successful, failed, stale, and undone action in an owner-scoped history.
- Refuse stale proposals instead of overwriting changes made in Shopify after a proposal was prepared.
- Undo eligible actions while the Shopify resource still matches Evolution's applied result.
- Measure discount redemption and before/after product or collection performance at 7, 14, and 30 days.

## Merchant control

The language model can prepare proposals but never receives an execution tool. A Shopify mutation can run only through the authenticated approval endpoint after the merchant clicks **Approve and apply**. Proposals expire after 24 hours, product batches are limited to ten items, and every execution is recorded.

## Shopify permissions

v1.1 adds `write_products`, `write_files`, and `write_discounts` to the existing order, checkout, and customer read access. Existing connected stores must reconnect once to approve the expanded permissions. The browser never receives a Shopify access token.

## Included action types

| Action | Applies | Undo |
| --- | --- | --- |
| Product update | Title, safe description HTML, SEO, tags, image alt text | Restore captured fields |
| Product draft | Create an unpublished listing | Archive the created draft |
| Collection upsert | Details, SEO, rules, sorting, membership | Restore updated collections; new collections are not auto-deleted |
| Code discount | Percentage, fixed, product-specific, minimum-spend, free shipping | Deactivate |
| Automatic discount | Reviewed automatic promotion | Deactivate |

## Explicitly deferred

v1.1 does not publish products, change prices or variants, adjust inventory, fulfill orders, mutate customers, edit raw theme code, send marketing email, or issue returns and refunds. These require separate permissions and higher-risk workflows.
