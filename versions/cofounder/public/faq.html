Simple answers.

What is Evolution?

An AI co-founder workspace for solo founders. Four roles help with product, technology, finance and growth.

How do I start?

Enter your product idea. Review the proposed MVP, then approve the scope and work with each role.

What can it do today?

Prepare MVP plans, product specifications, implementation code, test drafts, pricing analysis and launch content in chat. Download your workspace as a Markdown file.

Does it run code or send messages?

Not in this early hosted version. Code is a draft until you run and test it. Outreach stays as a draft. Repository execution and account connections will require their own setup and approval.

Can I talk to the avatar?

Yes. The workspace includes the existing 3D avatar, text chat and optional voice features. Voice input depends on your browser and microphone permission.

What does it cost?

No payment is required for this early-access version. Future pricing will be shown before any purchase.

Where is my work saved?

Your workspace is saved in this browser under your signed-in account. Download a copy before clearing browser data or switching devices. AI requests go through the existing authenticated server connection; if the AI service is unavailable, you will see an error.

Where did the ecommerce product go?

The ecommerce version is preserved separately. This site is now focused on AI co-founders; it does not run your existing ecommerce automations from this workspace.
